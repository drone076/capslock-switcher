## 🎯 Проблема

`CapsLock` — самая бесполезная клавиша на клавиатуре. Она занимает удобное место под мизинцем, но используется разве что для написания ЗАГЛАВНЫХ БУКВ (что можно сделать через `Shift`).

А ведь это идеальное место для переключателя раскладки!

### Почему не существующие решения?

**Punto Switcher:**
- ❌ Тяжеловесный (сотни мегабайт)
- ❌ Лезет в буфер обмена и автозамену
- ❌ Требует .NET Framework
- ❌ Работает нестабильно в Windows 11

**PowerToys Keyboard Manager:**
- ❌ Требует установки всего набора PowerToys
- ❌ Излишне сложен для такой простой задачи

**Другие аналоги:**
- ❌ Жрут память
- ❌ Показывают иконки в трее
- ❌ Отправляют телеметрию

---

## ✨ Решение

**Capslock Switcher** превращает бесполезную клавишу `CapsLock` в самый удобный переключатель раскладки.

- ✅ **Весит ~150 КБ** (весь дистрибутив ~200 КБ)
- ✅ **Написан на Rust** — быстрый, безопасный, без зависимостей
- ✅ **Работает везде** — во всех приложениях, включая системные окна
- ✅ **Невидимый** — нет окна, нет иконки в трее, нет уведомлений
- ✅ **Простой** — делает одну вещь и делает её идеально
- ✅ **Нулевое потребление ресурсов** в фоне
- ✅ **Мгновенная реакция** (< 1 мс)

## 🚀 Установка

### Быстрая установка (рекомендуется)

1. Скачайте последний релиз: [**CapslockSwitcher_Setup.zip**](https://github.com/drone076/capslock-switcher/releases/latest)
2. Распакуйте архив в любую папку
3. Запустите `install.bat`
4. Подтвердите запрос прав администратора (UAC)
5. Готово! ✨

Программа автоматически:
- Скопирует себя в системную папку
- Добавится в автозагрузку
- Настроит запуск с нужными правами

При следующем входе в систему она тихо запустится в фоне и будет работать.

### Ручная установка

Если вы предпочитаете контролировать всё вручную:

1. Скачайте `capslock_switcher.exe` из [релизов](https://github.com/drone076/capslock-switcher/releases/latest)
2. Скопируйте его в удобное место (например, `C:\Utils\`)
3. Создайте ярлык и поместите его в папку автозагрузки:
   - Нажмите `Win + R`, введите `shell:startup`, нажмите Enter
   - Скопируйте ярлык в открывшуюся папку
4. Кликните правой кнопкой по ярлыку → **Свойства** → **Дополнительно** → ✅ **Запуск от имени администратора**

## 📖 Как использовать

Просто нажимайте `CapsLock` вместо `Alt+Shift` или `Ctrl+Shift` для переключения раскладки.

**Важно:** После установки программы клавиша `CapsLock` больше не включает режим заглавных букв. Если вам нужно написать что-то заглавными буквами, используйте `Shift` + нужные клавиши.

## ❓ FAQ

### Как удалить программу?
Запустите `uninstall.bat` из дистрибутива, либо вручную удалите:
- Файл `capslock_switcher.exe` из `C:\Program Files\CapslockSwitcher\`
- Ярлык из папки автозагрузки (`shell:startup`)

### Программа не видна в трее. Это нормально?
Да, это сделано намеренно. Программа работает полностью в фоне, не потребляет ресурсы и не отвлекает внимание. Она просто делает свою работу.

### Поддерживается ли Windows 10?
Да, программа работает в Windows 10 и Windows 11.

### Можно ли использовать CapsLock и для переключения, и для заглавных букв?
Сейчас — нет. Программа полностью заменяет функционал `CapsLock`. Но если вам нужно написать что-то заглавными буквами, используйте `Shift` + нужные клавиши.

## 🛠️ Для разработчиков

Если вы хотите собрать проект самостоятельно или внести изменения:

### Требования
- Rust 1.70+ ([rustup](https://rustup.rs/))
- MinGW-w64 (для кросс-компиляции из Linux)
- zip, dos2unix (для создания дистрибутива)

### Установка зависимостей (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install mingw-w64 zip dos2unix
```

### Добавление Windows-цели в Rust
```bash
rustup target add x86_64-pc-windows-gnu
```

### Сборка
```bash
# Настроить линковщик
mkdir -p .cargo
cat > .cargo/config.toml << EOF
[target.x86_64-pc-windows-gnu]
linker = "x86_64-w64-mingw32-gcc"
EOF

# Собрать проект
cargo build --release --target x86_64-pc-windows-gnu

# Уменьшить размер
x86_64-w64-mingw32-strip target/x86_64-pc-windows-gnu/release/capslock_switcher.exe
```

Готовый .exe будет в target/x86_64-pc-windows-gnu/release/.

### Автоматическая сборка дистрибутива
```bash
chmod +x build.sh
./build.sh
```

Это создаст папку dist/ с готовым ZIP-архивом для распространения.
