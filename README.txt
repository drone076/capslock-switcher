ЧТО ЭТО ЗА ПРОГРАММА?
---------------------
Capslock Switcher — это минималистичная утилита для Windows, которая превращает
бесполезную клавишу CapsLock в удобный переключатель раскладки клавиатуры.

Вместо того чтобы тянуться к Alt+Shift или Ctrl+Shift, вы просто нажимаете
CapsLock одним пальцем — и раскладка переключается мгновенно.


КАК ЭТО РАБОТАЕТ?
-----------------
- Нажатие CapsLock → переключает раскладку (RU ↔ EN)
- Shift + CapsLock → включает/выключает режим заглавных букв (обычный CapsLock)

Программа работает полностью в фоне, невидима, не потребляет ресурсы и не
показывает никаких окон или иконок в трее.


УСТАНОВКА
---------
1. Распакуйте архив CapslockSwitcher_Setup.zip в любую папку
2. Запустите файл install.bat
3. Подтвердите запрос прав администратора (нажмите "Да" в окне UAC)
4. Готово! Программа установится и запустится автоматически

Что происходит при установке:
- Программа копируется в папку C:\Program Files\CapslockSwitcher\
- Создается задача в Планировщике заданий Windows для автозапуска
- Программа регистрируется в списке "Программы и компоненты"
- Программа запускается сразу после установки


ИСПОЛЬЗОВАНИЕ
-------------
Просто нажимайте CapsLock для переключения раскладки.

Если вам нужно написать текст заглавными буквами:
- Зажмите Shift и нажимайте нужные буквы
- Или нажмите Shift + CapsLock, чтобы включить режим заглавных букв

Программа работает во всех приложениях, включая:
- Браузеры
- Текстовые редакторы
- Диспетчер задач
- Системные окна Windows


УДАЛЕНИЕ
--------
Способ 1 (рекомендуется):
1. Откройте "Параметры" → "Приложения" → "Установленные приложения"
   (или "Панель управления" → "Программы и компоненты")
2. Найдите в списке "Capslock Switcher"
3. Нажмите "Удалить"

Способ 2:
1. Перейдите в папку C:\Program Files\CapslockSwitcher\
2. Запустите uninstall.bat
3. Подтвердите запрос прав администратора

Что происходит при удалении:
- Программа останавливается
- Удаляется задача из Планировщика заданий
- Удаляется запись из "Программы и компоненты"
- Удаляются все файлы программы


ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
-------------------------
В: Программа не видна в трее. Это нормально?
О: Да, это сделано намеренно. Программа работает полностью в фоне и не
   отвлекает внимание.

В: Почему при запуске программы появляется окно UAC?
О: Это нормально только при первом запуске или ручной установке. После
   установки программа будет запускаться автоматически без UAC-запросов.

В: Можно ли использовать CapsLock и для переключения раскладки, и для
   заглавных букв одновременно?
О: Да! Просто CapsLock переключает раскладку, а Shift + CapsLock включает
   режим заглавных букв.

В: Программа работает в Windows 10?
О: Да, поддерживаются Windows 10 и Windows 11.

В: Как проверить, что программа запущена?
О: Откройте Диспетчер задач (Ctrl+Shift+Esc), перейдите на вкладку
   "Подробности" и найдите capslock_switcher.exe в списке процессов.
