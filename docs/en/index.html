How to use

1

Download and extract

Download the CapslockSwitcher_Setup.zip archive and extract it to any folder.

2

Run install.bat

Double-click install.bat and confirm the administrator privileges request (UAC).

3

Done!

The program installs and starts automatically. Now press CapsLock to switch keyboard language.

Frequently asked questions

Can I use CapsLock for both switching and uppercase letters?

Yes! Simply press CapsLock to switch language, and Shift + CapsLock to enable uppercase mode.

The program is not visible in the tray. Is this normal?

Yes, this is intentional. The program works completely in the background and doesn't distract you.

Is Windows 10 supported?

Yes, the program works on Windows 10 and Windows 11.

How do I uninstall the program?

Open Settings → Apps → Installed apps, find "Capslock Switcher" and click Uninstall.
